# Damireddy Ashok Reddy — Portfolio

A project-first personal portfolio built with React, TypeScript, and Vite. The visual direction uses cinematic terracotta, warm cream, sand, and charcoal sections, with responsive layouts and restrained motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Netlify

- Build command: `npm run build`
- Publish directory: `dist`

The repository includes `_redirects` for SPA-safe routing. Project covers are CSS illustrations, so they remain crisp and do not rely on stock imagery. Repository links are only clickable when supplied as verified links; live demos open independently.
